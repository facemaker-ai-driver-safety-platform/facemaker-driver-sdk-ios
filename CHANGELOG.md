# Release notes

## 0.1.1 — 2026-11-04

First binary-only iOS SPM distribution. Includes current shared detection fixes for sustained drowsiness/fresh GPS/repeated warnings, phone-mount and normal-turn stability, and bounded optional diagnostics. Native SDK, queue/normalizer, engine and in-app UI are supplied as four XCFrameworks. Original SDK implementation sources, credentials and private test fixtures are excluded. Includes English integration documentation and a SwiftUI host sample.
